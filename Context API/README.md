## О проекте

Цель — закрепить на практике:

- **Context API**: создание контекста, `Provider`, `useContext`, кастомные хуки для контекста.
- **Паттерн «два контекста»**: разделение данных и `dispatch` для уменьшения перерисовок.
- **`useReducer`**: управление сложной логикой состояния.
- **Мемоизация**: `React.memo`, `useMemo`, `useCallback` и «каскад мемоизации».
- **Кастомные хуки**: `useDebounce`, `usePrevious` и хуки для контекстов.
