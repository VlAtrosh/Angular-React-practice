## Чему учит проект

### Часть 7 — `localStorage`

- Что `localStorage` хранит **только строки** → `JSON.stringify` / `JSON.parse`
- Почему нельзя делать «эффект загрузки + эффект сохранения» — данные теряются при первом рендере
- **Ленивая инициализация** `useState(() => ...)` — читаем из хранилища один раз при монтировании
- Сохранение через `useEffect` с зависимостью `[key, value]`
- `try/catch` и на чтении, и на записи — приложение не падает на битых данных и в приватном режиме
- Кастомный хук **`useLocalStorage`** — переиспользуемая логика, API как у `useState`
- `crypto.randomUUID()` для уникальных `id` вместо `Date.now()`

### Часть 8 — React Router

- Зачем `BrowserRouter` (HTML5 History API) и куда его ставить — в `main.jsx`
- `Routes` + `Route`: `path` → `element`
- `Link` вместо `<a>` — без перезагрузки страницы
- `NavLink` — активное состояние через `({ isActive }) => ...`
- `useNavigate` — программный переход (`navigate('/dashboard')`, `navigate(-1)`)
- Динамические маршруты `:param` + `useParams` (возвращает **строки**)
- Layout-route `<Route element={<Layout />}>` без `path` + `<Outlet />`
- `*` — обработка 404
- Обработка несуществующего `:userId` прямо в компоненте
