## Возможности

- Добавление задачи с текстом и приоритетом (низкий / средний / высокий)
- Отметка выполнения (чекбокс, зачёркивание)
- Удаление задачи
- Редактирование по двойному клику (Enter — сохранить, Escape — отменить)
- Фильтры: Все / Активные / Выполненные (со счётчиками)
- Статистика: всего / активных / выполнено
- Цветная полоска слева по приоритету
- Пустые состояния: «Здесь пусто 🎉» и подсказка при фильтре «Выполненные»

## Чему учит проект

### Часть 3 — состояние и события

- `useState` для массива задач и строки инпута
- Функциональное обновление: `setTodos(prev => ...)`
- Иммутабельность: `[...prev, x]`, `.map`, `.filter` — без мутаций
- Controlled components: `value` + `onChange` у `input` и `select`
- `onSubmit` + `e.preventDefault()` — без перезагрузки страницы
- События `onChange`, `onClick`, `onKeyDown`, `onDoubleClick`
- Условный рендер пустого состояния
- Подсчёт производных данных (`doneCount`, `activeCount`) в рендере

### Часть 4 — списки, условия, стили

- Рендер списка через `.map` со стабильным `key={todo.id}` (не `index`)
- 4 способа условного рендера:
  - `&&` — сообщение про отсутствие выполненных
  - тернарник — режим редактирования в `TodoItem`
  - ранний `return` — пустой список в `TodoList`
  - словарь — цвета приоритетов `priorityColors`
- Вложенные компоненты и передача колбэков через пропсы
- Локальное состояние (`isEditing`, `editText`) живёт в `TodoItem`, а не в `App`
- Разные способы стилизации: инлайн-стили + глобальный CSS
- Производные данные считаются в рендере, не дублируются в state

## Поток данных

```
App (state: todos, filter)
  │
  ├── TodoForm     ← onAdd={addTodo}
  │       → вызывает addTodo({ text, priority }) при сабмите
  │
  ├── Filters      ← current={filter}, onChange={setFilter}, counts
  │       → вызывает setFilter('active') при клике
  │
  └── TodoList     ← todos={visibleTodos}, onToggle, onDelete, onEdit
        │
        └── TodoItem ← todo={todo}, onToggle, onDelete, onEdit
              │
              └── TodoItem имеет СВОЁ локальное состояние isEditing
```

**Принципы:**
- `App` владеет глобальным состоянием (`todos`, `filter`)
- Дети получают данные через пропсы, изменения — через колбэки
- Локальное состояние (`isEditing`) — там, где нужно, в `TodoItem`
- Производные данные (`visibleTodos`, `counts`) считаются в рендере
