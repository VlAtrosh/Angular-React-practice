# Каталог студентов — учебный React-проект

Учебное приложение на **React + TypeScript**: каталог студентов с карточками,
статистикой и навыками. Сделано по методичке «React: Части 1–2»
(введение, JSX, компоненты, пропсы).

Проект живёт внутри ASP.NET Core-шаблона (`HybridApp.Server`),
поэтому фронтенд лежит в `ClientApp/react`. C#-часть для задач
по React не используется — работаем только с фронтендом.
